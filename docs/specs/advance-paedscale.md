# Spec — Advance PaedScale + preprint (journal-grade)

Branch: `claude/project-thread-7cgfis`. Draft PR only; merged by the owner when everything is done.

## Order (owner's priority)
1. **CI** — GitHub Actions running every deterministic (no key, no network) test on push/PR.
2. **Fair benchmark** — reproducible, no API key, harness-only (never imported by product code):
   - Reference set built from public FDA labels (DailyMed/openFDA): adult dose and pediatric
     dose per labeled age band, each with set_id, label version/effective date and a verbatim quote.
   - Pre-specified inclusion/exclusion rules and model-input rules (fm, target metric) written
     *before* results are computed; no tuning to the reference.
   - Comparators: weight-linear, BSA (weight-only formula), allometry-only (WT^0.75),
     PaedScale (allometry × maturation). Same inputs for every method.
   - Metrics: fold error, % within 0.67–1.5× and 0.5–2×, AAFE/AFE, within-labeled-range,
     paired comparison vs each comparator, bootstrap CIs; stratified by age band (neonates headline).
   - Figures + CSV regenerated by one command; CI checks the benchmark runs.
3. **Uncertainty layer** — seeded Monte Carlo over the *published* 95% CIs of TM50/Hill →
   90% prediction interval for CL, half-life and dose + per-pathway variance share.
   Wired into the compute tool output and shown in the UI. Covers parameter uncertainty only.
4. **Manuscript** — bioRxiv (Pharmacology & Toxicology), written so it can go to a journal:
   methods (engine, cite-or-abstain agent, uncertainty), benchmark results, limitations,
   AI-use statement, every reference verified against PubMed/DOI. PDF + source in `paper/`.

## Constraints (from CLAUDE.md)
- No invented maturation curves; MATURATION only from published TM50/Hill (+ their CIs).
- Product path never reads `eval_data/` or `validation_set/`; no `result*.md` files.
- TDD for code; code-review after every commit.

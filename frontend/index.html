Pediatric dose-extrapolation agent

Dosing children where the guidelines run out.

PaedScale derives a defensible starting dose for a child from adult pharmacokinetics — using allometry × organ maturation, with a cited, auditable rationale. Decision support, not a prescription.

The gap PaedScale encodes

Drug clearance does not scale linearly with body size in early life — the organs that eliminate the drug are still maturing. Scaling an adult dose by weight over-doses the young. PaedScale models the distance between the naïve linear line and the true maturation curve.

The formula, term by term

Pediatric clearance is adult clearance scaled by size (allometry) and by how mature the eliminating organ is (Anderson–Holford maturation function), then by organ function when labs support it. See References.

# per elimination pathway
CL_child = CL_adult × (WT/70)^0.75 × MF(PMA) × OF
MF(PMA)  = PMA^H / (TM50^H + PMA^H)  # normalised so adult ≈ 1
# maintenance (Css/AUC): dose_rate_child = adult_dose_rate × CL_child/CL_adult
# peak (Cmax): dose_child = adult_dose × Vd_child/Vd_adult    Vd ∝ WT^1.0
CL_adult / CL_childClearance (L/h). Adult value is retrieved (cited); child value is computed, never invented.
(WT/70)^0.75Allometric size scaling to a 70 kg adult. Exponent 0.75 is standard for metabolic clearance (not linear mg/kg).
MF(PMA)Maturation fraction from postmenstrual age. Sigmoid Hill function reaches ~1 in adults.
PMAPostmenstrual age in weeks (gestational + postnatal). Required for under-2s; if unknown we assume term and flag it.
TM50, HAge at 50% maturation and Hill coefficient for a pathway (e.g. renal_gfr, cyp3a4). Published parameters only — the engine refuses unknown pathways.
OFOrgan-function modifier. Renal: bedside Schwartz eGFR from height + creatinine. Hepatic: Child-Pugh noted only (drug-specific; no silent OF invent).
Target metricCss/AUC scale dose rate on clearance; Cmax on volume; time>MIC uses the Css solve but is flagged as a proxy for fT>MIC.

Evidence grades A → D

Every recommendation carries a grade so you can see how much weight to put on the number — concordance against a real pediatric guideline when one exists, honesty when it does not.

A
Guideline-concordant

Solid PK and the extrapolated dose falls within the clinical concordance band (0.67×–1.5×) of a real pediatric guideline.

B
Solid PK, no check

Retrieval and engine path are sound, but no usable guideline was found — or concordance is directional only (e.g. time>MIC proxy).

C
Sparse / uncertain

Data gaps, large assumptions, or engine limits. Treat as directional only; verify before any clinical use.

D
Insufficient / stop

Cannot defend a dose: unretrievable PK, safety hard-stop (contraindication, toxic threshold, non-viable route), or abstain.

When you see a grade, treat it as how much weight to put on the number — A is concordance-backed; D means no dose should be ordered from this run.

Grade mix: A 3 · B 46 · C 7 · D 4. The dominant B reflects honesty, not weakness — the agent refuses false certainty and flags PD assumptions, TDM, and engine-vs-guideline tension. Strict-band misses cluster on known, self-reported limits (aminoglycoside Cmax under-prediction, β-lactam time>MIC daily-dose proxy, Michaelis–Menten phenytoin) — surfaced, then guideline-anchored, never hidden.

PaedScale is a research prototype for decision support — not prescribing. It turns adult pharmacokinetics into a defensible pediatric starting dose using published allometry and organ-maturation science, live literature retrieval, and an auditable grade.

Built as an open experiment in transparent pharmacometrics: Python owns the arithmetic; the language model owns pathway judgment and prose — never silent invention of PK numbers.

Concept · not yet in the product

From allometry to a digital twin of the child.

Today PaedScale bends one maturation curve per elimination pathway. The next step is to model the whole physiology — a physiologically-based PK (PBPK) model of the child, validated against real clinical concentrations, then personalised to the patient in front of you. This is where pediatric dosing becomes individualised medicine.

Generalised vs personalised medicine

Most pediatric “starting doses” in guidelines are generalised: they describe a typical child of a given age/weight band. PaedScale today is still generalised — one maturation curve per pathway, applied to this child’s size and age — but it is transparent about that. Personalised medicine asks a harder question: what dose for this genotype, this organ function trajectory, and this measured concentration history?

GENERALISED (TODAY)

Population curves, one child

  • Adult PK scaled by allometry × Anderson–Holford maturation for the mapped pathway(s)
  • Covariates: weight, PMA/age, optional renal eGFR, noted hepatic Child-Pugh
  • Same published TM50/Hill for every patient on that pathway
  • Fast, auditable, cite-or-abstain — ideal when guidelines thin out
  • Limitation: does not model full organ tree, genotype, or Bayesian TDM feedback
PERSONALISED (FUTURE)

A digital twin of this child

  • PBPK: gut, liver, kidney, blood, tissues with age-appropriate sizes and flows
  • Genotype (e.g. CYP2D6, CYP3A5, UGT) changes pathway capacity, not just a flag
  • Measured eGFR, albumin, and prior levels update the twin (MAP Bayesian / MIPD)
  • Virtual populations expose exposure distributions, not only a point estimate
  • Still decision support — but individualised within a validated physiology model

Generalised ≠ “wrong” — it is the honest default when individual data are sparse. Personalised models reduce residual unexplained variability when those data exist and the model is validated against pediatric concentrations.

Physiologically-based PK — the whole body, not one curve

Instead of a single lumped clearance, a PBPK model routes the drug through the organs that actually absorb, distribute, metabolise and excrete it — each one sized and blood-perfused for the child's age. Maturation, organ function and drug properties fall out of the physiology itself.
